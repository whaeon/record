### T-24 · 图表可读性强化

**目标**：降低双 Y 轴认知负担，增加封板率阈值警戒线与情绪背景色带。

**范围边界**
- 允许修改：图表组件配置
- 禁止修改：API、数据结构
- 禁止操作：不得推翻现有双 Y 轴结构重做

**关键约束**
1. 封板率折线增加阈值虚线（默认 60%，可在图表设置中调整）。
2. 背景色带表示情绪区间：封板率高于阈值偏红、低于阈值偏绿，透明度低不干扰数据线。
3. 图例清晰标注左右轴对应指标。
4. 手机端色带与警戒线仍可辨。

**验收标准（逐条自检并汇报）**
1. 封板率警戒线正确显示在阈值位置。
2. 背景色带按情绪区间着色，不遮挡数据线。
3. 图例左右轴标注清晰。
4. 手机端与暗色下可读。
5. 原有数据线、tooltip 行为不变。

**完成后**：停止等待验收。清理只在人工「T-24 验收通过」后按 WORKFLOW 执行。

### T-25 · 空状态 / 加载 / 错误处理统一

**目标**：统一全站空状态、加载状态、错误提示的视觉与交互。

**范围边界**
- 允许修改：所有页面的状态展示组件、前端 API 调用封装
- 禁止修改：API 接口
- 禁止操作：不得改变业务逻辑

**关键约束**
1. 空状态统一使用 shadcn/ui 的空状态组件，含图标、标题、说明、可选操作按钮。
2. 加载状态统一使用 Skeleton 或 Spinner，列表与图表各有对应形态。
3. 接口失败统一 Toast 提示，含错误摘要与重试按钮。
4. 后端未启动时前端显示明确提示「服务未连接」，而非白屏。
5. 所有页面覆盖：策略列表为空、指标无数据、复盘无记录、图表无数据。

2. 接口失败时 Toast 含重试按钮。
3. 后端未启动时前端显示「服务未连接」。
4. 加载状态在列表和图表上表现一致。
5. 暗色与手机端正常。

**完成后**：停止等待验收。清理只在人工「T-25 验收通过」后按 WORKFLOW 执行。

### T-26 · source 字段前端展示

**目标**：在指标表格与 tooltip 中用极小角标区分手动录入（manual）与自动计算（auto）。

**范围边界**
- 允许修改：指标表格、图表 tooltip、批量录入页
- 禁止修改：数据结构（source 字段已存在）
- 禁止操作：不得改变 source 的写入逻辑

**关键约束**
1. manual 不显示角标（默认），auto 显示一个小圆点或「A」角标，颜色与主题协调。
2. 图表 tooltip 中注明该数据点来源。
3. 批量录入页新增的数据默认为 manual。
4. 角标不干扰数字阅读，悬停显示「自动计算」或「手动录入」。

**验收标准（逐条自检并汇报）**
1. auto 数据在表格与 tooltip 中有清晰但不突兀的标识。
2. manual 数据不显示角标。
3. 悬停提示文案正确。
4. 暗色与手机端正常。

**完成后**：停止等待验收。清理只在人工「T-26 验收通过」后按 WORKFLOW 执行。
