### T-19 · 数据备份与导出

**目标**：提供导出能力（指标 CSV、复盘 Markdown 打包）与自动备份（每日 pg_dump，保留最近 N 份）。

**范围边界**
- 允许修改：后端导出接口、备份脚本或启动逻辑、前端导出按钮、docker-compose 备份挂载
- 禁止修改：数据结构
- 禁止操作：不得引入第三方备份服务

**关键约束**
1. 新增 `GET /api/export/metrics.csv` 与 `GET /api/export/notes.md`（打包为 zip）。
2. 导出内容包含当前用户 schema 下的全部数据，CSV 含表头。
3. 备份：每日首次启动或定时任务执行 `pg_dump`，输出到宿主机挂载目录，文件名含日期，保留最近 14 份。
4. 前端在设置或工具区提供「导出数据」按钮，触发下载。
5. 备份失败时记录日志，不阻塞应用启动。

**验收标准（逐条自检并汇报）**
1. 导出 metrics.csv 可在 Excel 打开，列与字段一致。
2. 导出 notes.zip 含每日 Markdown 文件，内容正确。
3. 备份文件按日期生成，超过 14 份时最旧的被清理。
4. 备份失败时应用仍正常启动，日志有记录。
5. 前端导出按钮可用，暗色与手机端正常。

**完成后**：停止等待验收。清理只在人工「T-19 验收通过」后按 WORKFLOW 执行。

**目标**：在指标表格与 tooltip 中用极小角标区分手动录入（manual）与自动计算（auto）。

- 禁止修改：数据结构（source 字段已存在）
