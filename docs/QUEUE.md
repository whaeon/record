## 任务简报

### T-30 · 复盘默认预览 + 新建

**目标**：进入复盘默认 Markdown 预览；空记录显示空状态与「开始编写」。点编辑才左右（或手机切换）编辑/预览。「新建复盘」= 选日期（默认今日）进入编辑。同一任务内按 T-27 删除被替换的默认编辑布局死代码。

**范围边界**
- 允许修改：复盘页交互与空状态
- 禁止修改：API 接口
- 禁止操作：不得改变 Markdown 能力集；不得默认进入编辑态

**关键约束**
1. 从其他页切入复盘：有内容则预览，无内容则空状态，不直接进入编辑。
2. 「开始编写」/「编辑」进入编辑；手机仍列表/编辑/预览切换，桌面编辑时左右对照。
3. 「新建复盘」弹出日期（默认今日）；已有内容则打开该日编辑。
4. 左侧列表选中即预览该日。

**验收标准（逐条自检并汇报）**
1. 从策略回顾进入复盘，默认不是编辑器。
2. 空日显示空状态 + 开始编写。
3. 新建可选日期，默认今日。
4. 编辑态桌面左右对照、手机切换正常。
5. 暗色正常。

**完成后**：停止等待验收。清理只在人工「T-30 验收通过」后按 WORKFLOW 执行。
