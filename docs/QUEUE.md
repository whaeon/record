## 任务简报

### T-32 · 图表策略名旁简述

**目标**：策略回顾图表每个策略标题行，策略名右侧用非强调色展示 `current_detail` 简述，一眼能看出策略内容。

**范围边界**
- 允许修改：frontend 图表策略标题（MetricsChart ChartGrid）
- 禁止修改：API 接口；strategies 表结构
- 禁止操作：不得新开接口取简述；用已有 GET /api/strategies 的 current_detail

**关键约束**
1. 简述与策略名同一行：名称为强调（现有 font-medium），简述为 muted、truncate，不换行撑高标题。
2. 停用策略仍显示「（已停用）」，简述跟在名称后。
3. 空 current_detail 不渲染简述，不留空白占位。
4. 手机与桌面同一套标题行。

**验收标准（逐条自检并汇报）**
1. 每个有内容的策略小图标题能看到简述。
2. 长文本截断，不把图表顶出布局。
3. 暗色下简述弱于策略名。
4. 未新增 API。

**完成后**：停止等待验收。清理只在人工「T-32 验收通过」后按 WORKFLOW 执行。
